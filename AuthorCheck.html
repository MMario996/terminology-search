How Rules & Custom Prompts works

  • + Create New Rule / AI Prompt creates a new rule or a custom AI prompt. Pick an existing category or create a new one, choose whether it's a strict "Rule" or a free-form "AI Prompt", give it a title and description, and (for AI Prompts) a detailed instruction that Gemini follows when checking a document.
  • The categories (Abbreviation, Grammar, ...) can be expanded. Each rule has a checkbox to turn it on or off. Only enabled rules are actually used the next time you run a check.
  • Save Settings saves your changes permanently: it stores which rules are on/off for your account, and it writes the full rule set, including any custom rules, to a file called active_rules.json in a Google Drive folder named "TermCheck Rules" in your own Google Drive.

Export, Import & sharing with a colleague

  • JSON Export writes your current rule set, exactly as shown right now in this popup, to that same active_rules.json file in the "TermCheck Rules" folder in your Drive. This folder is created automatically the first time you save or export, it is private to your own account, not shared automatically.
  • JSON Import lets you pick a JSON file from your computer and load its rules into this popup. Rules with the same internal name overwrite the existing one, rules with a new name are added. Import only changes what you see here, nothing is saved yet at this point.
  • Important: an import only takes effect once you click Save Settings afterwards. If you close the popup without saving, the imported rules are discarded.
  • To share your rules with a colleague:
    1. Click JSON Export (or Save Settings) to make sure your Drive file is up to date.
    2. Open Google Drive, find the "TermCheck Rules" folder in your My Drive, and either share the active_rules.json file directly with your colleague, or download it and send it however you like, e.g. email or Teams.
    3. Your colleague opens their own Rules & Custom Prompts popup, clicks JSON Import, selects the file you sent, checks that it looks right, and clicks Save Settings. This saves it into their own account and their own Drive folder.
  • This is a one-time snapshot, not a live sync. If you change your rules later, you need to export and share the file again for your colleague to get the update.
